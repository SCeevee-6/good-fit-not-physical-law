# Chronological real-clock noise challenge

Freeze after inspecting file metadata and initial lines only. Input: AllanTools Cs5071A 1 s phase differences (cesium vs hydrogen maser), Git blob 3092941352deef03c5c966fd9f3fcb5d24f0d465. This is a semi-synthetic injection challenge on measured noise: no unknown natural event labels or independent hardware resets.

Split record chronologically in thirds, discarding incomplete 128-s blocks separately in each third. First third: estimate constant frequency trend by median block endpoint slope; estimate independent read variance and accumulating Brownian variance by nonnegative least squares on increment variance vs lag at 1,2,4,8,16,32 s, using squared robust Gaussian-equivalent MAD scale, relative-error weights. No subsequent tuning. Second third is a comparator calibration set. Last third is the sealed evaluation. Keep all complete blocks; no outlier removal.

At h=4,16,64 s, inject either sign of a positive linear frequency ramp from 0 to m through the last h seconds of a block, integrating it to obtain phase. Evaluate both signs on each block (paired, not independent). Read every second in that window. Compare endpoint differencing, triangular drift-only weighting of increments, and the mixed-noise likelihood filter for the ramp pair. Select m analytically so the mixed filter forecasts 90% in each window; other filters see the identical signal. Score empirical worst-sign accuracy, balanced accuracy and both model and comparator predictions. Primary gate: absolute difference between 90% and observed worst-sign accuracy ≤3 percentage points at all three h. Comparator predicts per-sign errors directly from second-third empirical noise tails. Report time-block variation in four successive evaluation segments. No hardware accuracy or new metrological priority claim.
